# Lisboa no Tempo

Uma experiência interativa para explorar Lisboa num mapa 3D e descobrir histórias associadas a lugares históricos.

## Experiência inicial
- Navegação no mapa com zoom, rotação e inclinação.
- Pontos históricos selecionáveis e filtros por época.
- Fichas narrativas com cronologia e fontes de referência.
- Layout responsivo para desktop e dispositivos móveis.

## Publicar no GitHub Pages
A publicação é automatizada por GitHub Actions em cada push para `main`.

1. Em **Settings → Pages**, escolha **GitHub Actions** como source se ainda não estiver definido.
2. Verifique a execução em **Actions**.
3. Quando o workflow terminar, abra https://gui816.github.io/lisbon-history/

## Tecnologias
- MapLibre GL JS
- Carto basemap (estilo Dark Matter)
- HTML, CSS e JavaScript
- GitHub Actions / GitHub Pages

## Dados e atribuição
O mapa utiliza serviços cartográficos remotos e as suas respetivas condições de uso. Os textos históricos desta versão são introdutórios e devem ser validados antes de serem usados como conteúdo editorial definitivo. As imagens são imagens ilustrativas remotas; não representam necessariamente fotografias do acontecimento descrito.

Projeto experimental — primeira versão.
